# Seguretat

Si trobes una vulnerabilitat, no obris una issue pública. Comunica-la amb [GitHub Security Advisories](https://github.com/nil-munte/calcul-cost-trajecte/security/advisories/new).

L'abast inclou les regles de Firestore (`firestore.rules`) i qualsevol manera d'accedir a dades d'un altre usuari.
